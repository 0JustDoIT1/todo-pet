## 모듈: 모바일 앱

- 패키지명(applicationId / bundle ID)은 출시 후 바꿀 수 없다. 정한 값을 바꾸지 않는다.
- 앱 바이너리에 들어가는 설정 파일에는 공개 가능한 값(공개 키, URL)만 넣는다. 서버·스크립트용 비밀값 파일을 앱 빌드 옵션에 넘기지 않는다.
- 권한(위치, 카메라, 알림)은 PRD에 있는 것만 요청한다. 새 권한이 필요하면 먼저 보고한다.
- 실기기가 없는 플랫폼의 동작은 "미검증"으로 보고한다. 에뮬레이터에서만 확인했으면 그렇게 적는다.
- 서명 키, 키스토어, 스토어 계정 정보는 저장소에 두지 않는다.
