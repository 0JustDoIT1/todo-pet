## 1. 목적
- 해결하려는 문제: 할일 관리는 보상이 약해서 꾸준히 쓰기 어렵다. 할일 완료로 얻은 포인트를 펫 돌보기에 쓰게 해서 계속 쓰고 싶게 만든다.
- 이 프로젝트로 보여주고 싶은 것 (포트폴리오 관점): 1인 개발로 Flutter 로컬 우선 앱을 완성하고, AI 생성 에셋 작업 흐름으로 그래픽 제작 비용을 줄인 사례.
- Phase 1에서는 핵심 순환(할일 → 포인트 → 펫)이 재미있는지 검증한다.

## 2. 대상 사용자와 핵심 시나리오
- 할일을 관리하며 가벼운 보상을 원하는 사용자
- 할일 등록 → 완료 → 포인트 적립 → 먹이 구매·급여 → 펫 반응 확인

## 3. MVP 기능 (Phase 1)
| ID | 기능 | 완료 기준 |
| --- | --- | --- |
| F1 | 할일 | 원타임·반복·체크리스트 생성, 조회, 수정, 삭제 및 완료. 세부 규칙은 3.1 |
| F2 | 할일 화면 | 오늘·캘린더·완료 목록에서 할일 확인. 캘린더는 날짜를 고르면 그날 할일(반복 회차 포함)을 보여준다 |
| F3 | 포인트 | 난이도 하/중/상 완료 시 5/10/20P 지급, 모든 지급·차감을 PointHistory에 기록. 세부 정산은 3.2 |
| F4 | 펫 | 시작 펫 2~3종 중 1마리 선택·이름짓기, 활성 펫 1마리 표시, 기분·배고픔 관리, 기본 먹이 3종, 남은 시작 종 추가 입양과 활성 펫 교체. 세부 규칙은 3.3 |
| F5 | 상호작용 | 펫 탭 반응 1종(반응은 항상, 기분 상승은 하루 10회까지), 1~2단계 고정 위치 idle 모션. 표현 방식은 3.5 |
| F6 | 온보딩 | 펫 선택·이름짓기·첫 할일 등록과 첫 완료 보상 안내 |

모든 수치는 **초기값(조정 가능)**이다. 바꾸면 이 표와 `docs/decisions.md`에 남긴다.

### 3.1 할일 규칙
- 빠른 등록: 제목만 입력, 오늘 날짜·난이도 하로 저장.
- 상세 등록: 난이도, 카테고리(고정 8종 중 선택, 선택 항목), 날짜, 반복, 하위항목.
- 원타임 할일은 날짜가 필수다(기본 오늘).
- 반복은 매일 또는 요일 선택만 지원한다.
- 체크리스트는 원타임처럼 날짜를 갖고 이월된다. 하위항목은 진행률만 보여주고, 모두 체크하면 할일이 완료된다.
- 오늘 할일과 이월된 할일만 완료할 수 있다. 미래 날짜 원타임은 날짜를 오늘로 바꾸면 완료할 수 있다.
- 이월된 할일에는 "N일 지연"을 표시한다.
- 수정은 이후 회차에만 적용한다. 완료된 할일은 수정할 수 없고, 당일 취소한 뒤 수정한다.
- 삭제해도 지난 기록과 지급된 포인트는 유지한다.

### 3.2 포인트 정산 규칙
- 잔액은 PointHistory 합계다.
- 시작 포인트는 0P.
- 일일 적립 상한은 100P. 오늘 적립 합계(취소 차감 반영)로 계산한다. 상한을 넘은 완료도 이력에 0P로 기록하고, 나중에 여유가 생겨도 소급해 올리지 않는다.
- 할일 회차(할일 + 날짜)마다 유효한 지급은 최대 1건이다. 완료를 취소하면 지급 당시 금액만큼 차감 이력(음수)을 남기고, 다시 완료하면 다시 지급한다.
- 완료 취소는 당일에만 할 수 있다. 차감으로 잔액이 음수가 될 수 있으며, 음수인 동안에는 구매할 수 없다.
- 반복 할일은 회차마다 지급한다.
- 체크리스트는 전체 완료 시 난이도 포인트를 한 번 지급한다.

### 3.3 펫 상태 규칙
- 이름은 1~10자.
- 기분·배고픔은 0~100이며 초기값은 80이다.
- 백그라운드 작업 없이, 앱을 열 때 마지막 갱신 시각부터 지난 시간으로 감소분을 계산한다. 시간당 감소량은 구현 때 초기값을 정해 decisions.md에 기록한다.
- 기분은 탭과 먹이로 오르고, 표정 표시에만 쓴다(3.5).
- 먹이는 상점에서 구매하면 바로 활성 펫에게 급여한다(보관함은 Phase 2). 먹이는 배고픔 회복·기분 상승·경험치를 준다.
- 배고픔이 100이면 먹이를 살 수 없다.
- 가장 싼 먹이는 5P 이하로 한다(온보딩 첫 완료만으로 먹이를 살 수 있게).
- Phase 1 성장은 1→2단계뿐이며 누적 경험치로 올라간다(3단계부터는 Phase 2).
- 추가 입양: 상점에서 아직 없는 시작 종을 포인트로 입양한다(초기값 300P). 새 펫은 1단계·초기 상태로 시작한다.
- 시작 종을 모두 입양하면 상점의 입양 영역을 숨긴다.
- 활성 펫은 설정에서 교체한다. 활성 펫이 아닌 펫은 상태가 변하지 않는다. 비활성 기간은 감소 계산에서 뺀다(교체할 때 갱신 시각을 다시 잡는다).

### 3.4 날짜 넘김 처리
- 앱을 열 때(그리고 앱을 켜 둔 채 자정을 넘길 때) 마지막 처리일 다음 날부터 어제까지를 하루씩 처리한다.
  - 미완료 원타임 할일을 다음 날로 이월한다.
  - 미완료 반복 회차를 결석으로 기록한다.
- 같은 날짜를 두 번 처리하지 않는다.
- 기기 시간 조작에는 대응하지 않는다(1인용 로컬 앱).

### 3.5 펫 그래픽 (개발 시점 AI 생성)
- 그래픽은 개발할 때 AI 이미지 생성으로 만들어 앱에 넣는다. 앱은 실행 중에 AI를 호출하지 않는다.
- 종·성장 단계마다 시트 1장(1행 × 4칸, 칸당 64×64): `기본 | 눈 감음 | 기쁨 | 배고픔`.
- 표정 선택 순서: 배고픔 30 이하 → 배고픔 칸, 기분 70 이상 → 기쁨 칸, 그 외 → 기본 칸(눈 감음과 교대).
- 움직임은 코드로 만든다: idle은 위아래 흔들림, 탭 반응은 기쁨 칸 + 점프.
- 입양 펫도 시작 종 그림을 그대로 쓴다.
- 생성 규칙·프롬프트는 `docs/ART_PROMPTS.md`, 출처는 `ASSETS.md`.

## 5. 불변식
절대 깨지면 안 되는 규칙. CLAUDE.md 프로젝트 구역에도 옮겨 적는다.
- 포인트 지급과 사용은 이력에 기록하고 중복 지급하지 않는다.
- 활성 펫은 한 마리이며 교체해도 각 펫의 성장 상태를 보존한다.
- 기분·배고픔이 낮아져도 질병·죽음 페널티를 주지 않는다.
- 미완료 원타임 할일은 다음날 이월하고, 반복 습관은 결석으로 기록한다.
- 일일 기준은 현지 자정 00:00으로 한다.

## 6. 데이터 모델
DB(Drift)에는 사용자 데이터만 둔다.
- Todo: 종류(원타임·반복·체크리스트), 제목, 난이도, 카테고리, 날짜 또는 반복 요일
- ChecklistItem: 체크리스트 하위항목과 체크 여부
- TodoOccurrence: 할일 + 날짜 + 상태(완료·결석). 포인트 중복 지급 방지 기준
- PointHistory: 금액(음수 포함), 사유, 관련 회차, 시각
- Pet: 종, 이름, 단계, 경험치, 기분, 배고픔, 마지막 갱신 시각, 오늘 탭 횟수
- UserProfile: 활성 펫, 마지막 날짜 처리일, 온보딩 완료 여부

종(PetSpecies)·먹이(FoodItem)·카테고리(Category 8종)는 코드 상수로 둔다.
기획서의 ShopItem, UserInventory, PlacedItem, PetEvent, PetBehaviorProfile, 스트릭 집계는 후속 Phase에서 구체화한다.

## 7. 화면 목록
- 하단 탭: 홈·할일·상점·설정
- 홈: 활성 펫과 오늘 할일 미리보기, 포인트 잔액
- 할일: 오늘·캘린더·완료 보기, 등록(빠른·상세)·상세 화면
- 상점: 먹이 3종 구매(구매 즉시 급여), 시작 종 입양
- 설정: 활성 펫 교체·이름 변경, 오픈소스 라이선스·에셋 출처 보기
- 온보딩: 펫 선택 → 이름짓기 → 첫 할일 등록 → 첫 완료 보상 안내. 완료 전에 앱을 끄면 다시 열 때 처음부터

## 8. 기술 결정 요약
상세는 `docs/decisions.md`.
Flutter, Riverpod, Drift/SQLite, 로컬 우선, 한국어 우선. 펫 그래픽은 개발 시점 AI 생성 정적 에셋(1×4 표정 시트 + 코드 모션), 런타임 AI 호출 없음. 정확한 버전과 플랫폼별 배포 범위는 미정이다.

## 9. 미확정 사항과 위험
- Android/iOS 동시 출시 여부와 최소 OS 버전
- 시작 펫 종과 디자인
- AI 이미지 생성 도구의 상업 이용 조건 확인 (출시 전)
- 시간대 이동 시 일일 기준 처리
- 기분·배고픔 시간당 감소량, 먹이 3종 가격·효과, 1→2단계 성장 경험치, 입양 가격(초기값 300P) 조정
- 위험: 로컬 전용이라 앱을 지우면 데이터가 사라진다(백업은 Phase 3.5~4)
